# Практическая работа №4

**Дисциплина:** Основы программной инженерии  
**Тема:** Операторы цикла. Циклические алгоритмы.  
**Уровень:** базовый (A)

## Состав работы

- **A1.py** — тренажёр таблицы умножения: случайные примеры, проверка ответов, повтор ввода при неверном формате и статистика времени/результатов.
- **A2.py** — рисование прямоугольника, правого треугольника и рамки с помощью вложенных циклов.
- **A3.py** — анализ последовательности сетевых пакетов: количество потерь, самая длинная серия потерь, процент потерь и оценка качества связи.
- **A4.py** — проверка контрольной суммы номера банковской карты по алгоритму Луна.

## Запуск

1. Откройте папку `Lab_4` в Visual Studio Code.
2. Выберите нужный файл.
3. Откройте **Terminal → New Terminal**.
4. Выполните команду, например:

   ```bash
   python A1.py
   ```

   Для остальных заданий замените имя файла на `A2.py`, `A3.py` или `A4.py`. Каждая программа запускается отдельно.

## Примечание по A4

В задании предлагается разобрать валидатор из лекции 6. Текст лекции 6 в предоставленных материалах отсутствовал, поэтому здесь реализована стандартная проверка контрольной суммы Луна. Её стоит сверить с примером преподавателя, если он отличается.
