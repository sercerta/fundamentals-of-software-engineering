# Практическая работа №3

**Дисциплина:** Основы программной инженерии  
**Тема:** Реализация алгоритмов ветвления. Условные операторы.

В папке представлены решения заданий базового уровня **A**.

## Состав работы

- **A1.py** — проверка того, находятся ли две точки в одной координатной четверти; при совпадении четверти выводится её номер.
- **A2.py** — проверка пароля по требованиям задания: длина 8 символов, заглавные и строчные латинские буквы, цифры, специальные символы `*`, `-`, `#` и отсутствие других символов.
- **A3.py** — расчет использованного объема газа по двум показаниям циклического счетчика, суммы оплаты и средней цены одного кубометра.

## Требования

Для запуска необходим Python 3. Внешние библиотеки не требуются; в A2 используется стандартный модуль `string`.

## Запуск

Откройте терминал в этой папке и выполните нужную команду:

```bash
python A1.py
python A2.py
python A3.py
```

Вводите данные в консоль в соответствии с условием задачи. В A1 координаты вводятся по одному числу на строке; в A2 вводится пароль; в A3 сначала вводится предыдущее, затем текущее показание счетчика.

## Примечание

В A3 счетчик циклический: после показания 9999 следующее показание равно 0. Тариф рассчитывается по диапазонам последовательно: первые 300 м³ включены в фиксированную плату 21 $, следующие 300 м³ стоят 0,06 $ за м³, следующие 200 м³ — 0,04 $ за м³, остаток свыше 800 м³ — 0,025 $ за м³.
