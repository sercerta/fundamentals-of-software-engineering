# Основы программной инженерии

Репозиторий содержит практические работы по дисциплине «Основы программной инженерии».

## Практическая работа 2

**Тема:** типы данных Python, приведение типов и решение задач на работу с числовыми данными.

В папке `Lab_2` находятся решения заданий базового уровня A:

- **A4.py** — поиск наибольшего из двух целых чисел.
- **A5.py** — проверка делимости чисел.
- **A6.py** — перевод секунд в формат электронных часов.
- **A7.py** — определение цвета шахматных клеток.

## Запуск программ

Для запуска необходим Python 3.

Перейдите в папку `Lab_2`, откройте терминал и выполните команду, например:

`python A4.py`

Аналогично запускаются остальные программы: `A5.py`, `A6.py` и `A7.py`.

В программах, запрашивающих ввод, вводите данные в соответствии с условием задачи.
