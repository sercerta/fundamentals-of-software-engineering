# Практическая работа 2 — типы данных Python

Дисциплина: «Основы программной инженерии».

## Задания базового уровня

- **A1** — определить значения и типы выражений `width // 2`, `width / 2.0`, `height / 3`, `1 + 2 * 5`.
- **A2** — определить возможность преобразования выражений в целое число с помощью `int()`. Важно различать `ValueError` (неподходящая строка) и `TypeError` (несовместимые типы).
- **A3** — перевести 1 921 000 байт в мегабайты по основанию 1024 и проверить размер объекта с помощью `sys.getsizeof()`.
- **A4.py** — вывести большее из двух целых чисел без ветвлений, циклов и пользовательских функций.
- **A5.py** — вывести `YES`, если A делится на B нацело, иначе `NO`.
- **A6.py** — вывести время, прошедшее с начала суток, в формате `h:mm:ss`.
- **A7.py** — определить, одного ли цвета две клетки шахматной доски; клетка (1, 1) считается белой.

## Запуск

Требуется Python 3. Сохраните входные данные в стандартном вводе или введите их в терминале при запуске:

```bash
python A4.py
python A5.py
python A6.py
python A7.py
```

Для каждой программы вводите значения по одному в строке. Например, для `A6.py` можно ввести `3602`; ожидаемый результат — `1:00:02`.
